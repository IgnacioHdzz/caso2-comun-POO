# Jungle Attack — Librería común

Caso #2 de POO

**Autores:** Ignacio Hernández y Julian Moya

Clases que comparten el [servidor](https://github.com/IgnacioHdzz/caso2-servidor-POO) y el [cliente](https://github.com/IgnacioHdzz/caso2-cliente-POO) de *Jungle Attack*: el protocolo de mensajes, la lectura y escritura por sockets y las clases base del modelo, que cada programa extiende con lo suyo.

## Cómo usarla

Los otros dos proyectos la usan como dependencia de Maven.
